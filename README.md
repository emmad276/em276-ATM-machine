# ATM Machine Code Project
## Overview
This project is an interactive ATM Machine application built using JavaScript and TypeScript. The application allows users to authenticate with a PIN, check their balance, withdraw amounts, and use fast cash options.

## Features
PIN Authentication: Secure access to the ATM functionalities with a PIN code.
Balance Checking: View the current account balance.
Withdrawals: Withdraw a specified amount from the account.
Fast Cash Options: Quickly withdraw preset amounts.
Asynchronous Operations: Utilizes asynchronous prompts for smooth user interactions.
